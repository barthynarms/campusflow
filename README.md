# campusflow

Project Goal: CampusFlow

To Build CampusFlow, a Python command-line ticket manager that replaces Learn2Earn’s informal, easily lost technical support reports with a structured, reliable system. CampusFlow lets campus staff record problems such as Wi-Fi outages, faulty laptops, broken development environments, and inaccessible platforms. It prioritizes work, assigns responsibility, and tracks each issue through to resolution.
